# Contributor Covenant Code of Conduct

Coding Super Hub adopts the Contributor Covenant Code of Conduct, version 2.1.

The complete canonical text is maintained at:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project, including issues, pull requests, discussions, reviews, and other project spaces, contributors agree to follow the Contributor Covenant v2.1.

## Scope

This code applies to all project spaces and to public spaces when an individual is representing Coding Super Hub or its community.

## Reporting

For sensitive conduct concerns, contact the maintainers privately using the reporting channel in [SECURITY.md](SECURITY.md). Reports should include enough context to investigate while avoiding unnecessary personal information.

## Enforcement

Maintainers will apply the Contributor Covenant v2.1 Community Impact Guidelines fairly and confidentially. Enforcement may include correction, warning, temporary restrictions, or permanent removal depending on the circumstances.
