# Code of Conduct

## Our pledge

We are committed to making participation in Coding Super Hub welcoming, respectful, and harassment-free for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while addressing technical problems directly.
- Give actionable feedback focused on the code or proposal.
- Respect privacy and do not publish secrets or personal information.
- Welcome contributors with different experience levels.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized conduct, doxxing, deliberate disruption, and publishing private information without permission are not acceptable.

## Enforcement

Project maintainers may remove comments, reject contributions, or restrict participation when behavior violates this policy.

To report a conduct concern, use the private security contact described in SECURITY.md when appropriate, or open a GitHub issue when the report is not sensitive.
